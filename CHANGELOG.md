# Changelog

All notable changes to Mercury are documented here.

## [1.0.0] - 2026-09-25

### 🎉 Initial Release

#### Features
- **Smart GitHub Cloning** — Paste any GitHub URL to clone repositories
- **Auto Project Detection** — Supports Python, Node.js, .NET, Rust, Go, Java, PHP, Ruby, C/C++, Docker
- **One-Click Install** — Automatically installs project dependencies
- **Build & Run** — Build and launch projects with a single click
- **Security Scanning** — Commands classified as Safe/Review/Dangerous before execution
- **Real-Time Logs** — Full operation logging with expandable detail views
- **Drag & Drop** — Drop folders or URLs directly onto the app
- **Dark Theme UI** — Modern, professional WPF interface
- **CLI Tool** (`mercury`) — Full command-line interface for power users
- **Context Menu** — Optional "Install with Mercury" right-click integration
- **Self-Contained** — No .NET runtime installation required

#### Installation
- Windows installer (Inno Setup) with wizard
- Desktop shortcut and Start Menu entries
- Optional PATH and context menu integration
- Silent install support (`/VERYSILENT`)
- Clean uninstall via Windows Settings
