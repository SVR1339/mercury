MERCURY — UNIVERSAL GITHUB & TERMINAL INSTALLER
===================================================

What does Mercury do?
---------------------
Mercury makes it effortless to install and run any GitHub project or
command-line install script on your computer.

Simply:
  1. Paste ANY command or repo URL:
     • PowerShell one-liner (irm ... | iex)
     • Apple Terminal / Unix one-liner (curl ... | bash)
     • Git clone command (git clone https://github.com/...)
     • Package manager install (pip install git+..., npm, cargo)
     • Or GitHub shorthand (owner/repo)
  2. Mercury identifies the command or project automatically
  3. Mercury executes the download, sets up dependencies, and grants needed permissions
  4. One-click access to PowerShell, Command Prompt, and Apple Terminal

Supported project types:
  - Python (pip, conda, poetry, pipenv)
  - Node.js (npm, yarn, pnpm)
  - .NET / C# (dotnet)
  - Rust (cargo)
  - Go (go build)
  - Java (maven, gradle)
  - PHP (composer)
  - Ruby (bundler)
  - C/C++ (cmake, make)
  - Docker (docker-compose)

Requirements:
  - Windows 10 version 1809 or later (64-bit) / macOS 11+ (Intel & Apple Silicon)
  - Git recommended (https://git-scm.com)
  - Internet connection for downloading and running projects

No .NET runtime installation is needed — everything is fully self-contained!
